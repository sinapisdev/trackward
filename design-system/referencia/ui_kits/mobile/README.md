# UI kit — TrackWard mobile

`Painel.jsx` recreates 19-Mobile at 430×932: the same greeting, folder carousel, trilha,
radar and queue as the desktop overview, re-laid for one thumb, with the five-stop tab bar
(Painel · Você · Conversa · Tracks · Mais).

Only the mobile dashboard was supplied as source art. The other four tabs render a short
disclaimer instead of invented screens — extend them from the desktop kit when the real
designs exist.
