One-sentence: the workhorse row — leading affordance, title + context, right-side deadline, chevron if it opens something.

```jsx
<ListRow chevron leading={<Icon name="file-text" size={18} />} title="Conferir documentos"
  subtitle="Implantação do ERP" meta="Hoje" onClick={open} />
```

Active rows get a 2px lime inset bar on the left edge; hover is a 4% white tint.
