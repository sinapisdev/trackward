One-sentence: pair it with the percentage set in --fs-metric — the ring never carries the number inside it.

```jsx
<div style={{display:"flex",alignItems:"center",gap:14}}>
  <ProgressRing value={33} />
  <span style={{font:"var(--fw-bold) var(--fs-metric)/1 var(--font-display)",color:"var(--ink-0)"}}>33<span style={{fontSize:20}}>%</span></span>
</div>
```
