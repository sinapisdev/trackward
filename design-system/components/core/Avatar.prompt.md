One-sentence: two-letter initials on --bg-avatar; photos are supported but the product art is all-initials.

```jsx
<Avatar name="Leonardo Esteves" size="md" />
<AvatarGroup people={["Leonardo E","Ana N","Mariana C","Bruno R"]} max={3} />
```

Always pair an avatar with the person's first name in text when the row has space ("LE Leonardo", "Responsável: Leonardo").
