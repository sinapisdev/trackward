Trocar a senha do TrackWard

Alguém pediu uma senha nova para esta conta. Se foi você, use o botão abaixo. O link vale por uma hora e só funciona uma vez.

Definir a nova senha

Se o botão não funcionar, copie e cole este endereço no navegador:
{{ .SiteURL }}/auth/confirmar?token_hash={{ .TokenHash }}&type=recovery&proximo=/nova-senha

Se não foi você, pode ignorar: a senha continua a mesma.
